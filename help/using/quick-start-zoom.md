# Kurzanleitung: Zoom{#quick-start-zoom}

Mit Zoom können Sie interaktiv hochauflösende Details in Bildern anzeigen. Sie können beispielsweise Bilddetails in einem dynamischen, vollständig konfigurierbaren, integrierten Viewer anzeigen. Dieser Viewer kann in eine Web-Seite eingebettet werden oder in einem Popup-Fenster angezeigt werden. Um Bilder genauer zu betrachten, können Sie sie vergrößern und mit hoher Auflösung schwenken. Zoomen bietet Benutzern ein ansprechendes, informatives und interaktives Anwendererlebnis.

Adobe Dynamic Media Classic bietet auch geführtes Zoomen - eine Möglichkeit, die wichtigen Funktionen eines Bildes hervorzuheben. Wenn Sie die Aufmerksamkeit der Betrachter beispielsweise auf ein Logo lenken möchten, können Sie ein Zoomziel für das Logo erstellen. Wenn Benutzer dieses Zoom-Ziel auswählen, zoomen sie zum Logo.

Alle Zoom-Bilder werden aus einzelnen primären Bildern, Grafiken und datenbankgestützten Attributen erstellt und bereitgestellt. Adobe Dynamic Media Classic Zooming reduziert den Zeit- und Kostenaufwand für die Erstellung und Bereitstellung von Bildern erheblich. Sie können mit Zoom-Viewern Bilder vergrößern und verkleinern. Der Zoom-Viewer verfügt über Schaltflächen, mit denen Sie zoomen und schwenken können. Sie können auch einen Schwenk durchführen, indem Sie den Mauszeiger auf dem Bildschirm bewegen. Mithilfe von Zoom-Viewer-Vorgaben können Sie den Zoom-Viewer konfigurieren, mit dem Sie Bilder vergrößern.

Der folgende Zoom-Schnellstart soll Ihnen dabei helfen, mit der Verwendung von Zoom-Techniken in Adobe Dynamic Media Classic zu beginnen. Führen Sie die Schritte 1 bis 6 aus. Nach jedem Schritt finden Sie einen Querverweis auf eine Themenüberschrift, unter der Sie weitere Informationen finden.

## &#x200B;1. Hochladen von Zoom-Bildern

Laden Sie Ihre Zoom-Bilder in Adobe Dynamic Media Classic hoch. Für ein optimales Zoomen empfiehlt Adobe Dynamic Media Classic, dass die längste Seite der Bilder mindestens 2.000 Pixel hat.

Wählen Sie in der globalen Navigationsleiste **[!UICONTROL Hochladen]** aus, um Bilder von Ihrem Computer oder Netzwerk in einen Ordner in Adobe Dynamic Media Classic hochzuladen. Siehe [Hochladen von Zoom-Bildern](uploading-zoom-images.md#uploading_zoom_images).

## &#x200B;2. Erstellen von Zoom-Zielen für geführtes Zoomen

Mit Zoom-Zielen können Sie bestimmte Teile eines Bildes identifizieren. Sie können beispielsweise die Teile eines Bildes hervorheben, die es eindeutig oder unverwechselbar machen. Im Fenster Zoom-Viewer werden Zoom-Ziele als Miniaturbilder an der Seite des Bildes angezeigt. Bei Auswahl der Miniaturansicht eines dieser Zoomziele wird automatisch der zugeordnete Bildausschnitt herangezoomt.

Um ein Zoom-Ziel zu erstellen, wählen Sie **[!UICONTROL Bearbeiten]** > Zoom-Ziele aus oder öffnen Sie ein Bild in der Detailansicht des Durchsuchen-Bedienfelds und wählen Sie **[!UICONTROL Zoom-Ziele]** aus. Verwenden Sie dann die Zoom-Tools auf der Seite des Ziel-Editors, um einen Teil des Bildes als Ziel auszuwählen. Siehe [Erstellen von Zoom-Zielen für geführtes Zoomen](creating-zoom-targets-guided-zoom.md#creating_zoom_targets_for_guided_zoom).

## &#x200B;3. Viewer-Vorgaben für Zoom einrichten

Mithilfe von Zoom-Viewer-Vorgaben wird der Stil und das Verhalten von Zoom-Viewern festgelegt. Wenn Sie Administrator sind, können Sie Viewer-Vorgaben für Zoom einrichten. In Adobe Dynamic Media Classic stehen Ihnen außerdem standardmäßige Viewer-Vorgaben für Zoom zur Verfügung.

Um eine Viewer-Vorgabe für den Zoom zu erstellen, klicken Sie in der globalen Navigationsleiste auf **[!UICONTROL Setup]** > **[!UICONTROL Viewer-Vorgaben]**. Klicken Sie auf der Seite „Viewer **[!UICONTROL Vorgaben“ auf]** Hinzufügen“, wählen Sie eine Plattform und einen Zoom-Viewer aus und klicken Sie dann auf **[!UICONTROL Hinzufügen]**. Wählen Sie dann Optionen auf der Seite `Configure Viewer` aus.

Adobe Dynamic Media Classic bietet **[!UICONTROL Viewer-Vorgabe zoomen]** Optionen, mit denen Sie den Schaltflächenstil und das Gesamterscheinungsbild des Viewers auswählen können. Sie können auch die Zoomeinstellungen für Ihre Website anpassen. Siehe [Einrichten von Viewer-Vorgaben für Zoom](setting-zoom-viewer-presets.md#setting_up_zoom_viewer_presets).

## &#x200B;4. Vorschau von Bildern mit dem Zoom-Viewer

Um das Zoomen anzuzeigen, können Sie Bilder in einem Zoom-Viewer in der Vorschau anzeigen.

Um sich mit verschiedenen Zoom-Viewer-Vorgaben und deren Darstellung des Zoom-Erlebnisses vertraut zu machen, wählen Sie ein Bild im Durchsuchen-Bedienfeld aus und klicken Sie auf **[!UICONTROL Vorschau]**. Wechseln Sie **[!UICONTROL Vorgaben]** > **[!UICONTROL Zoom]** und wählen Sie dann mit dem Menü „Zoom“ eine Vorgabe aus.

Die Zoomschaltflächen werden angezeigt. Sie können sehen, wie die Zoombilder auf der Website dargestellt werden. Wählen Sie die Zoom-Schaltflächen (und Zoom-Ziele) aus, um die Einstellungen der ausgewählten Viewer-Vorgabe für den Zoom zu testen. Siehe [Vorschau von Bildern mit verschiedenen Zoom-Viewern](previewing-image-assets-different-zoom.md#previewing_image_assets_with_different_zoom_viewers).

## &#x200B;5. Veröffentlichen von Zoom-Bildern

Durch das Veröffentlichen Ihrer Zoom-Bilder werden diese auf Dynamic Media-Bildservern platziert, sodass sie für Ihre Websites und Programme bereitgestellt werden können. Im Rahmen des Veröffentlichungsprozesses aktiviert Adobe Dynamic Media Classic URL-Zeichenfolgen. Diese URL-Zeichenfolgen rufen Zoom-Bilder von Dynamic Media-Bildservern auf Ihrer Website oder in Ihrem Programm auf.

Wählen Sie in der Symbolleiste für globale Navigation **[!UICONTROL Veröffentlichen]** aus. Wählen Sie im Dialogfeld „Veröffentlichen“ die Option **[!UICONTROL Veröffentlichen starten]**. Siehe [Veröffentlichen von Zoombildern](publishing-zoom-images.md#publishing_zoom_images).

## &#x200B;6. Verknüpfen von Zoom-Viewern mit einer Web-Seite

Adobe Dynamic Media Classic erstellt die URL-Legendenzeichenfolgen, die für das Zoomen von Bildern erforderlich sind, und aktiviert sie, wenn Sie Bilder auf Dynamic Media-Bildservern veröffentlichen. Sie können diese URL-Zeichenfolgen von der Seite **[!UICONTROL Vorschau]** kopieren. Nachdem Sie die URL-Zeichenfolgen kopiert haben, stehen sie für Ihre Websites und Programme zur Verfügung. Siehe [Verknüpfen von Zoom-Viewern mit einer Web-Seite](linking-zoom-viewers-web-pages.md#linking_zoom_viewers_to_your_web_pages)
