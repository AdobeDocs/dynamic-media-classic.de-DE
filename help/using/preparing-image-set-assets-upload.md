# Vorbereiten des Bildsets Assets auf den Upload{#preparing-image-set-assets-for-upload}

Stellen Sie vor dem Hochladen der Bilder, die Sie für das [!DNL Adobe Dynamic Media Classic] von Bildsets benötigen, sicher, dass die Bilder die richtige Größe und das richtige Format aufweisen.

Um einen Bildsatz mit mehreren Ansichten zu erstellen, benötigen Sie Bilder, die ein Element aus unterschiedlichen Perspektiven zeigen oder verschiedene Aspekte eines Elements darstellen. Ziel ist es, die wichtigen Merkmale eines Elements hervorzuheben, damit Betrachter das Erscheinungsbild oder die Funktion des Elements vollständig verstehen können.

Da die Benutzer die Bilder in einem Bildsatz heranzoomen können, vergewissern Sie sich, dass die längste Seite der Bilder mindestens 2000 Pixel hat. Adobe Dynamic Media Classic unterstützt viele Bilddateiformate, empfohlen werden jedoch verlustfreie TIFF-, PNG- und EPS-Bilder.

Detaillierte Anweisungen zum Hochladen von Assets finden Sie unter [Dateien hochladen](uploading-files.md#uploading_files).
